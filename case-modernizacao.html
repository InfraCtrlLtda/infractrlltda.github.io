De servidores locais que caíam a uma operação em nuvem, com DR e custo menor

A jornada da Modernização com a InfraCtrl: sair dos servidores locais da prefeitura, ganhar disponibilidade na IBM Cloud, migrar o banco para Linux reduzindo custo e chegar a uma operação monitorada e acompanhada por um time todos os dias.

O desafio
Sistemas críticos de uma prefeitura rodando em servidores que caíam

A Modernização entrega software de gestão para o setor público: sistemas que uma prefeitura usa no dia a dia para atender o cidadão. O problema era onde eles rodavam: servidores locais dentro da prefeitura, que caíam com frequência. Sem redundância, sem plano de recuperação e sem monitoramento, cada queda derrubava serviços públicos e não havia como saber o que tinha acontecido nem quando voltaria.

Ponto de partida

  • Servidores locais na prefeitura, com quedas frequentes
  • Sem redundância e sem Disaster Recovery
  • Sem monitoramento: quedas descobertas na reclamação
  • Banco e aplicações amarrados a licenciamento Windows

Onde chegamos

  • Operação na IBM Cloud com DR configurado
  • SQL Server migrado para Linux (OpenShift), custo menor
  • Observabilidade com Uptime Kuma + Zabbix
  • ~99% de uptime e time atuando todos os dias

A jornada
Uma transformação em fases, não um "big bang"

Migrar uma operação pública inteira de uma vez seria arriscado. Fizemos por etapas, cada uma entregando um ganho concreto antes da próxima.

01 · Saída dos servidores locais

Para a IBM Cloud, com Hyper-V, SQL Server e DR

Tiramos os sistemas dos servidores locais da prefeitura e levamos para a IBM Cloud, virtualizando com Hyper-V e rodando o SQL Server em Windows, já com Disaster Recovery configurado. Só sair do on-premises instável para uma nuvem com redundância acabou com as quedas diárias e deu o primeiro salto de disponibilidade.

02 · Maturidade e observabilidade

Time técnico dedicado + Uptime Kuma e Zabbix

Com a operação estável na nuvem, colocamos um time técnico atuando todos os dias e a observabilidade de verdade: Uptime Kuma e Zabbix monitorando disponibilidade e saúde do ambiente. A partir dos dados, passamos a aperfeiçoar continuamente o SQL Server, os servidores e os Tomcats.

03 · Redução de custo

SQL Server e aplicação para Linux, com OpenShift

Com a base madura, migramos o SQL Server de Windows para Linux e levamos a operação para OpenShift. Saindo do licenciamento Windows, reduzimos o custo da operação sem abrir mão de estabilidade.

04 · Modernização de aplicação (em andamento)

De Tomcat em Windows para Linux + Docker

Hoje estamos ajudando a migrar as aplicações de Tomcat em Windows para Linux com Docker (containers), simplificando a operação, facilitando novas versões e reduzindo custo mais uma vez.

O impacto
Serviço público sem interrupção, para quem depende dele

A Modernização entrega sistemas que uma prefeitura usa para atender o cidadão todos os dias. Sair dos servidores locais instáveis para uma operação em nuvem com DR e time diário significa que esses serviços continuam no ar mesmo quando algo dá errado — e que a equipe da Modernização não precisa mais tratar infraestrutura como um problema recorrente. A migração para Linux/OpenShift também reduziu o custo de licenciamento, liberando orçamento para investir no produto em vez de manter a operação em pé.
